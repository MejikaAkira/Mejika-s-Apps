# 2026-07-18 ロビ TTS（Qwen3-TTS 0.6B）実装計画

## 決定事項（ユーザー回答）

1. **声モデル**: `generate_custom_voice` / `generate_voice_clone` を設定で切替可能。  
   **初期値は CustomVoice**。声クローンが必要なら Base に切り替え。
2. **読み上げ対象**: チャット返答 **および** 実況（キャプション）も含める。
3. **第一ゴール**: Phase 0→1（全文できてから読み上げ）まで実装してよい。

## 方針

- クラウドの Qwen-TTS Realtime API は使わない。**ローカル GPU** の Qwen3-TTS 0.6B。
- 専用モジュールを切り、GUI（`robot.py`）と組み合わせる。
- MVP: LLM/VLM 応答が完了したら、感情タグ除去後の本文を TTS → 再生。

## モデル

| variant | HF model_id | API | 初期 |
|---------|-------------|-----|------|
| `custom_voice` | `Qwen/Qwen3-TTS-12Hz-0.6B-CustomVoice` | `generate_custom_voice` | **○** |
| `voice_clone` | `Qwen/Qwen3-TTS-12Hz-0.6B-Base` | `generate_voice_clone` | 設定切替 |

- 日本語初期話者: `Ono_Anna`（CustomVoice）
- Base 時: `robot_data/voice/` の `ref_audio` + `ref_text`

## アーキテクチャ

```
chat / 実況完了
  → テキスト正規化（emotionタグ除去・空スキップ）
  → TtsWorker (QThread)
       → TtsClient.synthesize (GPU, lock)
       → sounddevice 再生
```

## フェーズ

### Phase 0 — 単体検証
- CustomVoice で短い日本語を合成・再生
- VRAM / 所要時間を確認

### Phase 1 — MVP（本実装スコープ）
- チャット返答完了 → 読み上げ
- 実況ノート表示時 → 読み上げ
- UI: 音声ON/OFF
- OOM/失敗時はチャット継続、ステータスバーにエラー

### Phase 2（後続・今回スコープ外）
- 文単位の追い読み（トークンバッファ → 句点でキュー）

## GPU / VRAM（RTX 3060 Laptop 6GB）

- VL(~2.4GB) + TTS(0.6B) はギリギリ → **直列化**（チャット/キャプション/TTS合成を同時に走らせない）
- `flash-attn` は Windows ビルドが重いため初期は SDPA 等で起動
